Reading these results

  • Same hardware, model builds, prompts and load on both. What changed with the OS: the kernel (Talos 6.18 against Ubuntu's 7.0), the NVIDIA driver on the Spark (595 against 580), and the runtime: Kubernetes pods under containerd on Talos, tt serve and Docker on Ubuntu. The Spark ran the same vLLM image, by digest, on both.
  • The QuietBox 2 rows use the builds that ran on Ubuntu: the v1 bundles, not the fused-decode rebuilds the main page shows, which only ran on Talos.
  • Most QuietBox 2 differences are small, but under load several models reached their first token later on Talos, which cuts total throughput at 16 and 32 users. Single runs of four requests (the 1-user tests) move a few percent from run to run on either OS, so read single dots with that in mind and lean on the medians.

Method. Every run sent random prompts with a fixed output length and greedy sampling (temperature 0) through vllm bench serve. Each Talos test is matched to the newest Ubuntu run of the same model build, workload, prompt length and user count; the change is (Talos − Ubuntu) / Ubuntu.
